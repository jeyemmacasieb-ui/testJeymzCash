# testJeymzCash

JeymzCash is a console-based mobile wallet demo. It supports simulated cash-in, sending money between wallets, bill payments, mobile load purchases, balance checks, and transaction history.

Compile and run with Java 17 or newer:

```sh
javac JeymzCash.java
java JeymzCash
```

Demo wallets:

- `09171234567` (Alice Vance), PHP 5,000.00
- `09179876543` (Bob Vance), PHP 1,200.00

This is an in-memory learning project. It does not connect to GCash or any payment provider, and cash-in is simulated.
